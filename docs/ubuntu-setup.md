# Ubuntu Virtual Machine Setup

## Overview

This document describes the initial setup of the Ubuntu virtual machine used in the cybersecurity home lab.

The purpose of this system is to practice Linux administration, networking and defensive security.

---

## Virtual Machine Information

Operating System:

- Ubuntu 22.04 LTS

Virtualization Platform:

- UTM
- QEMU

Architecture:

- ARM64
