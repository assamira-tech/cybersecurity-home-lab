# Cybersecurity Home Lab Overview

## Purpose

This document describes the objectives, design and evolution of my cybersecurity home laboratory.

The goal of this lab is to build practical experience in system administration, networking, security monitoring and defensive cybersecurity.

---

## Lab Goals

- Practice Linux administration
- Understand network architecture
- Experiment with security configurations
- Develop defensive security skills
- Document technical learning progress

---

## Current Status

Project initialized.

The laboratory environment will progressively include:

- Virtual machines
- Network configurations
- Security tools
- Monitoring solutions
- Automation scripts

---

## Skills Developed

### System Administration
- Linux command line
- File permissions
- User management
- System configuration

### Networking
- IP addressing
- TCP/IP fundamentals
- DNS concepts
- Network troubleshooting

### Cybersecurity
- Security hardening
- Log analysis
- Vulnerability assessment
- Defensive monitoring

---

## Documentation Approach

Each experiment will include:

- Objective
- Environment
- Configuration steps
- Security considerations
- Results and lessons learned
