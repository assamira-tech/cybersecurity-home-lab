# Virtualization Environment

## Overview

The cybersecurity home lab uses virtualization to create an isolated environment for security experiments and system administration practice.

---

## Host Machine

Operating System:

- macOS

Architecture:

- ARM64

Virtualization Platform:

- UTM
- QEMU virtualization

---

## Virtual Machine

Current Virtual Machine:

- Ubuntu 22.04 LTS

Purpose:

- Linux administration practice
- Security testing environment
- Networking experiments
- Defensive security exercises

---

## Lab Benefits

Virtualization provides:

- Safe testing environment
- Isolation from the host system
- Ability to reproduce configurations
- Practical Linux experience
